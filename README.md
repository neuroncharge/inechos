# INECHOS

Small-batch cookies website. Static site — open `index.html` in a browser, or serve the folder with any static server.

## Files
- `index.html` — markup
- `style.css` — styles (deep-forest theme)
- `app.js` — product data + rendering + WhatsApp order links
- `assets/` — images (hero + product photos)

## Customize
- Change WhatsApp number in `app.js` (`WHATSAPP_NUMBER`).
- Edit product data in the `products` object in `app.js`.
